# VELORA Finance Studio — версия 2.4

## Файлы
- `index.html` — структура сайта
- `styles.css` — оформление и адаптивность
- `app.js` — учет операций и локальное хранение

## Исправления версии 2.4
- Нижняя мобильная панель теперь оформлена в цвет активной темы, а не остается белой в темном режиме.
- Добавлен отступ под панелью с учетом safe-area на телефонах.
- Доходы выделены более ярким зеленым, расходы — коралловым, накопления — золотистым.
- Усилен контраст подписей, сумм и индикатора накоплений.
- Светлая тема сохраняет светлую нижнюю панель.

## Запуск
Откройте `index.html` или загрузите три файла в одну папку на статическом хостинге.

## Данные
Операции хранятся локально в браузере. Перед заменой файлов экспортируйте резервную копию JSON.
